# Easylsp plugin examples

Public test fixtures for io.github.easylsp.demo only. No hooks target other apps.
The early-symbol plugin changes the controlled int(int) function and preserves errno.
Build with Android NDK r28c, API 34, arm64, C17; export only easylsp_plugin_init_v1.
See the GPL license and source. Releases are immutable prepared test packages.
